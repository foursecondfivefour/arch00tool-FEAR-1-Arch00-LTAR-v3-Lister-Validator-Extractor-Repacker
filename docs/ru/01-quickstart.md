# Начало работы и моддинг

[К оглавлению](README.md) · [Команды](02-cli.md) · [Формат](03-format.md)

## Подготовка

Нужен Python 3.10+ со стандартными модулями, включая `zlib`. Установка сторонних пакетов не требуется. Запускайте команды из каталога со скриптом или укажите полный путь к `arch00tool.py`. В Windows при необходимости замените `python` на `py`. Пути с пробелами заключайте в кавычки. На диске понадобится место для извлечённых файлов, нового архива и временного файла. Не изменяйте входные файлы во время работы утилиты.

## Безопасный цикл работы

1. Сохраните оригинальный архив и файлы игры в резервной копии. Работайте с копией, не в каталоге игры.
2. Изучите содержимое и проверьте данные:

   ```bash
   python arch00tool.py list original.Arch00 -v
   python arch00tool.py test original.Arch00 -v
   ```

3. Извлеките содержимое в новый каталог:

   ```bash
   python arch00tool.py extract original.Arch00 extracted
   ```

4. Отредактируйте нужный ресурс подходящим инструментом. Сам скрипт не редактирует текстуры, модели или игровые форматы. Создайте отдельный каталог `mod` и поместите туда **только изменённые файлы**, сохранив их пути из архива. Например, для `Textures\\wall.dds` подготовьте `mod/Textures/wall.dds`. Регистр имён особенно важен на файловых системах, чувствительных к регистру. Сверяйте фактический путь с выводом `list`.
5. Соберите новый архив и проверьте его:

   ```bash
   python arch00tool.py repack original.Arch00 modded.Arch00 --replace-dir mod
   python arch00tool.py list modded.Arch00
   python arch00tool.py test modded.Arch00
   ```

   Сверьте `replaced=N`: отсутствующие файлы замены молча пропускаются, а лишние файлы в `mod` не добавляются в архив. Переименование, добавление и удаление записей не поддерживается. Если передать весь каталог `extracted`, будут заменены все совпадающие файлы, даже неизменённые; вместо этого лучше использовать отдельный каталог только с изменениями.
6. При необходимости извлеките собранный архив в ещё один пустой каталог и сравните изменённые файлы. Лишь затем проверяйте результат в игре, предварительно сохранив резервную копию. Способ установки и приоритет архивов зависят от игры и здесь не определены. Успешный `test` не доказывает, что игра примет архив или ресурс.

## Избирательное извлечение и пакеты

```bash
python arch00tool.py extract original.Arch00 textures --pattern '*.dds' -v
python arch00tool.py test-all archives
python arch00tool.py extract-all archives extracted-all --skip-existing
```

Шаблон `fnmatchcase` применяется к полному имени с обратными косыми чертами, чувствителен к регистру; `*` может соответствовать и разделителям каталогов. Экранирование кавычками важно, чтобы оболочка не раскрыла шаблон сама. Пакетные команды ищут файлы только непосредственно в заданном каталоге, без рекурсии.
