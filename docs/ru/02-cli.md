# Справочник команд

[К оглавлению](README.md) · [Начало работы](01-quickstart.md) · [Ограничения](05-safety.md)

Общий синтаксис: `python arch00tool.py КОМАНДА ...`. Опции конкретной команды следуют за её именем. Для отдельных подсказок используйте `python arch00tool.py extract --help` и т. п.

## `list АРХИВ [-v]`

Читает метаданные и выводит размер архива, версию, размер таблицы имён, количество каталогов и записей файлов, три флага и сырые байты GUID в hex. Для каждой записи выводит `stored_size -> unpacked_size`, `raw` при поле сжатия 0 или `method=N` иначе и полный путь. `-v`/`--verbose` дополнительно показывает список имён каталогов. Смещения файлов **не выводятся**. Содержимое не декодируется и не проверяется; неизвестный метод может отображаться без ошибки.

## `test АРХИВ [--compression auto|raw] [-v]`

Разбирает метаданные и обрабатывает каждую запись, направляя результат в системный пустой приёмник. В `auto` (по умолчанию) 0 означает копирование исходных байтов, 1–9 — поток zlib; другие значения для непустых записей приводят к ошибке. `raw` принудительно копирует сохранённые байты независимо от поля и не проверяет сжатый поток или совпадение размеров. Запись с нулевым `stored_size` допустима только при нулевом `unpacked_size`. Для raw-записей ненулевые размеры могут отличаться. `-v` печатает прогресс каждые 1000 проверенных непустых записей в stderr; выполнение останавливается на первой ошибке. CRC архива не проверяется.

## `extract АРХИВ КАТАЛОГ [--pattern ШАБЛОН] [--compression auto|raw] [-v]`

Создаёт выходной каталог при необходимости, отбирает записи по необязательному чувствительному к регистру `fnmatchcase`-шаблону полного архивного имени и извлекает в порядке смещений. Без шаблона извлекаются все записи. Шаблон без совпадений даёт успешное извлечение нуля файлов. Режимы сжатия как у `test`; `raw` выдаёт именно сохранённые байты, не обязательно пригодные как извлечённый ресурс. `-v` сообщает прогресс каждые 1000 файлов и на последнем. Файлы открываются с исключительным созданием: существующий файл не перезаписывается. При ошибке ранее созданные файлы и частично записываемый файл остаются на месте.

## `test-all КАТАЛОГ [--compression auto|raw]`

Проверяет непосредственно лежащие в каталоге файлы с расширением `.Arch00` без учёта регистра, по имени без учёта регистра. Для каждой ошибки обработки архива печатает `FAIL` и продолжает; в конце — числа успешных и ошибочных архивов. Если архивов нет, это ошибка. В отличие от `test`, параметра `-v` нет.

## `extract-all КАТАЛОГ ВЫХОД [--compression auto|raw] [--skip-existing] [-v]`

Ищет архивы так же, как `test-all`. Каждый извлекает сначала в `ВЫХОД/ИМЯ.Arch00.extracted.incomplete`, затем переименовывает каталог в `ВЫХОД/ИМЯ.Arch00.extracted`. При ошибке извлечения неполный каталог остаётся для диагностики; перед повтором его нужно проверить и вручную удалить или перенести. Существующий конечный каталог прерывает команду, если не указан `--skip-existing`; с ним он пропускается без проверки содержимого. Существующий `.incomplete` прерывает команду даже при `--skip-existing`, если конечного каталога нет. Ошибки при обработке отдельных архивов суммируются, но эти предварительные конфликты прерывают весь запуск.

## `repack АРХИВ ВЫХОД [--replace-dir КАТАЛОГ]`

Создаёт новый архив, не изменяя исходный. Без замен копирует сохранённые данные записей; при наличии обычного файла по соответствующему пути в каталоге замен использует его байты, записывает оба размера равными размеру файла и ставит поле сжатия 0. Не найденные замены игнорируются, лишние файлы не добавляются. Выводит число записей, сумму сохранённых байтов и число замен. Существующий выход и файл `ВЫХОД.partial` отклоняются. Проверяется совпадение SHA-256 каждого сохранённого диапазона с исходником или заменой, но не корректность zlib и не совместимость с игрой. См. [подробности пересборки](04-internals.md#пересборка).

## Коды завершения и потоки

- `0` — успешное выполнение, в том числе отсутствие совпадений шаблона или пропущенные каталоги.
- `1` — `test-all` или `extract-all` завершились с ошибками отдельных архивов.
- `2` — ошибка аргументов `argparse` либо обработанная верхним уровнем ошибка архива, файловой системы или переполнения.

Итоги обычно выводятся в stdout, прогресс и верхнеуровневые ошибки — в stderr; `FAIL` пакетных команд печатается в stdout. Не все исключения перехватываются: неожиданные ошибки Python могут сопровождаться traceback.
