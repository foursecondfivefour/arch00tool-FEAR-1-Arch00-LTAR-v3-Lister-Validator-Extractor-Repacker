# arch00tool

Однофайловая утилита на Python для просмотра, проверки, извлечения и пересборки архивов **LTAR v3 / `.Arch00`** (в том числе F.E.A.R.). Работает только со стандартной библиотекой Python; требуется Python 3.10 или новее.

```bash
python arch00tool.py list Some.Arch00 -v
python arch00tool.py test Some.Arch00
python arch00tool.py extract Some.Arch00 extracted/ --pattern '*.dds'
python arch00tool.py repack Some.Arch00 Some.modded.Arch00 --replace-dir mod/
python arch00tool.py test Some.modded.Arch00
```

Исходный архив не изменяется. Пересборка сохраняет неизменённые данные файлов, но **не обязательно создаёт побайтовую копию всего архива**. Файлы-замены записываются без сжатия; совместимость результата с конкретной игрой не гарантируется. Работайте с резервными копиями.
